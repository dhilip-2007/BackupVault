# BackupVault – Backup & Recovery Dashboard

BackupVault is a modern, responsive backup and recovery management dashboard built using HTML, CSS, and JavaScript. It provides a simple interface to monitor backup activity, view storage analytics, manage backup history, and simulate data recovery.

## 🚀 Live Demo

**[Open BackupVault Live Demo](https://dhilip-2007.github.io/BackupVault/)**

> If the demo does not open, enable GitHub Pages in the repository settings. See the deployment instructions below.

## ✨ Features

- 📊 Dashboard with backup statistics
- 💾 Storage usage visualization
- 🗂️ Recent backup history
- 🔍 Search and filter backup records
- ➕ Create backup simulation
- ♻️ Restore backup simulation
- 📥 Export backup reports as CSV
- 🛡️ Security status overview
- 📱 Responsive design for desktop and mobile
- 🎨 Clean, professional light theme

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Interactive dashboard features
- **Git and GitHub** – Version control and hosting
- **GitHub Pages** – Static website deployment

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/dhilip-2007/BackupVault.git
   ```

2. Open the project folder:

   ```bash
   cd BackupVault
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## 🌐 Deploy with GitHub Pages

1. Open the [BackupVault GitHub repository](https://github.com/dhilip-2007/BackupVault).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**.
6. Wait a few minutes and visit:

   https://dhilip-2007.github.io/BackupVault/

Make sure `index.html` is in the repository root.

## 🎯 Project Objective

The objective of BackupVault is to demonstrate how a backup and recovery management dashboard can be designed using frontend web technologies. It helps learners understand dashboard layouts, data visualization, table filtering, CSV export, and interactive UI components.

## ⚠️ Note

This is a **frontend demonstration project**. Backup creation and restoration are simulations; the application does not currently upload files to real cloud storage or perform actual data recovery.
