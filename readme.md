# BackupVault – Backup & Recovery Dashboard

A modern, responsive backup and recovery dashboard built with HTML, CSS, and JavaScript. BackupVault demonstrates backup monitoring, storage analytics, backup history, and simulated recovery through a professional web interface.

## 🌐 Live Demo

**[Launch BackupVault](https://dhilip-2007.github.io/BackupVault/)**

If the live demo is unavailable, follow the GitHub Pages setup instructions below.

## ✨ Features

- Dashboard overview and backup statistics
- Storage usage visualization
- Recent backup history
- Search and filter backup records
- Create backup simulation
- Restore backup simulation
- Export reports to CSV
- Security status overview
- Responsive layout for desktop and mobile
- Interactive interface using JavaScript

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

Make sure these files are in the repository's root directory. If your CSS or JavaScript files have different names, update the references in `index.html` accordingly.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/dhilip-2007/BackupVault.git
   ```

2. Open the project folder:

   ```bash
   cd BackupVault
   ```

3. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.

## ⚙️ Enable GitHub Pages

1. Open the [BackupVault repository](https://github.com/dhilip-2007/BackupVault).
2. Select **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch.
6. Choose the `/(root)` folder.
7. Click **Save**.
8. Wait for the deployment to finish, then open:

   **https://dhilip-2007.github.io/BackupVault/**

If GitHub Pages shows a deployment error, open the repository's **Actions** tab and inspect the latest Pages deployment.

## 🎯 Project Objective

This project demonstrates the frontend design of a backup and recovery management dashboard. It helps students practise responsive web design, JavaScript interactions, data tables, storage visualization, and CSV report export.

## ⚠️ Limitations

Backup creation and restoration are simulations. This frontend-only project does not currently upload files to real cloud storage, create actual backups, or recover real data.
